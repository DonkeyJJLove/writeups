# Canonical study artifacts

This directory contains the publication-level outputs of the completed confirmatory Heuristic Causal Lab run.

- `report.html` — rendered scientific report.
- `summary.json` — canonical aggregate metrics, paired contrasts, audit status and study verdict.
- `trials.csv` — all 10,240 scored episodes.

Runtime traces, raw HTTP exchanges, resumable study state and local execution folders are intentionally kept outside Git history. The code and durable research materials live in `../hcl_final_4_3/`.
